### The four critical notes

1. **Four consecutive releases have narrowed one guard's completeness claim** (F40→F41→F42→F43).
   Each fix was right; each claim was broader than what had been checked. The guard is now complete
   along three axes and **nobody has enumerated the axes**. What would close it is a dispatch-derived
   property test, which is on the ROADMAP and not in this release.
2. **What the bias report cannot see** — correctness, selection into the dataset at all, which
   `legacy_capture` rows are bad, and anything about pairs never evaluated.
3. **Which schema decision v0.9.0 will most want changed** — `dataset_observation.varbinds` as
   opaque JSON. The fix is additive, so nothing captured is lost, which is the test the decision had
   to pass.
4. **Is the sink's dual bound sufficient?** — measured, and no. The row cap governs, not the 21-day
   window, with honest caveats in *both* directions: the corpus overstates rows/trap, **and** the
   conclusion survives the caveat.

Finding series: **F43**. The next review continues from **F44**.

## 7. The release in one paragraph

v0.8.0 captures every evaluated correlation pair — the rejected ones as well as the linked ones,
before the cap truncates anything — plus an immutable record of what each alarm looked like at the
moment of decision, and, alongside each operator verdict, **the membership the server itself held**,
so a label survives the merges that used to destroy what it referred to. It measures that dataset's
bias in a deterministic report that doubles as a gate, and it says in that report what it cannot
know. It adds the product's first destructive control and builds it with preview, audit, and a
background loop structurally forbidden from destroying labels. It refuses one more class of
undeclared route. **It trains nothing**, adds no dependency, and leaves `make eval` byte-identical.
The two things a later reader should carry away are that the machine's own decision is present as
provenance and is not a target — enforced by the absence of a target column — and that the sink's
row cap, not its documented window, is what governs.
