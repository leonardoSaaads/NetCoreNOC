Migration is additive: no v0.1.0 row is altered, and the append-only triggers are live
immediately.

## Gate criterion 2 — `audit verify` passes on an empty chain

```
$ python -m opticorr audit verify
audit chain OK: 0 entries verified; final hash 0000…0000        (exit 0)
```

Extra coverage established while building the primitive:

- A 3-row chain verifies OK; `audit export` emits one NDJSON line per row plus the final
  chain hash on stderr.
- Tampering a middle row (via raw SQLite, triggers dropped to simulate an attacker with
  file access) is caught precisely: `audit chain BROKEN at id 2: entry_hash mismatch
  (row tampered) (after verifying 1 entries)`.
