```

test_dataset_shadow_cli_leads_with_the_sufficiency_verdict              PASSED
```

A four-bag, one-operator corpus produces `sufficient = 0`, `derivation_policy = 'none'`, **no

concentration floor prints `undefined` rather than a rate, because it falls when *another* operator

an extrapolation from one moment is a fabricated number and this release does not print one.
