## 1. Determinism

Fixed fold assignment (a rotation over **sorted** ids — no RNG), fixed resample seed, fixed row
ordering, no wall clock. `test_the_report_is_deterministic_across_two_runs` spawns a **subprocess**,
so the two-process half is measured rather than assumed.

**The bootstrap ships its own nine-line LCG** rather than using `random.Random`, because that
module's stability guarantee is about a *version* and not a *value* (DECISIONS #151). That decision
introduced a bug and a test caught it — see §3.

## 2. The power condition, validated against the plan's table

| incidents | plan | this build's closed form | independent Monte-Carlo |
|---:|---:|---:|---:|
| 12 | 0.42 | **0.524** | **0.52** |
| **37** | **0.25** | **0.298** | **0.33** |
| 120 | 0.16 | 0.166 | 0.18 |
| 300 | 0.10 | 0.105 | 0.11 |

**Agreement at large `n`; a material disagreement below 120, reported and not resolved**
(DECISIONS #142, Gate 1 §2). Two independent methods agree with each other and disagree with the
plan. Neither side was adjusted.

**The floors and the threshold are emitted together**, and after mutant M6 the guard reads the
**rendered output** rather than the source:

```
  floors met                                                no
  minimum detectable difference                          0.182
    at n incidents                                          100
```

The report says in words that these are two different claims — *floors met* says a fit would not be
degenerate; *the threshold* says whether a difference could be **resolved** at that `n`.

## 3. What the shipped bootstrap reproduces

```
  n=  12  plan 0.500   observed 0.500
  n=  37  plan 0.289   observed 0.297
  n=  50  plan 0.246   observed 0.260
  n= 100  plan 0.180   observed 0.180
  n= 500  plan 0.079   observed 0.080
```

**Reproduced by the shipped code**, not by a throwaway script — which is the difference between a
table that has been checked and a table that has been quoted.

It did not reproduce on the first attempt. `_Lcg.below` returned `state % bound`; a
power-of-two-modulus LCG has notoriously poor **low** bits, so `% 2` alternated with period 2, every
resample of a two-cluster corpus drew exactly one of each, and the interval came back **zero-width**
— a bootstrap reporting perfect precision because it never resampled anything.
`test_the_bootstrap_resamples_incidents_and_not_observations` caught it by asserting a two-cluster
corpus has a *wider* interval than a 200-cluster one. Both were `0.000`.

## 4. Every trigger fired by a purpose-built corpus that fires it and no other

Nine `Trigger` members, nine tests, plus `test_every_registered_trigger_is_reachable` — which guards
against a registered condition nothing can reach, since that is indistinguishable from one somebody
forgot to wire.

**`test_the_clean_corpus_fires_no_trigger_and_can_reach_better` is the control for the whole file.**
Every trigger test perturbs exactly one field of a corpus that fires nothing; if that baseline fired
something, or could never reach `BETTER`, each of the nine would pass for the wrong reason.

Triggers are **collected, not short-circuited**: the report says *which* conditions fired, and a
build that returned on the first would make the second invisible.
