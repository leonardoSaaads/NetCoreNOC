## Gate 3 criteria

- **The files exist and are project-specific.** `CONTRIBUTING.md` names NetCoreNOC's actual gates
  and constraints (zero new runtime deps, ingestion-is-sacred, bounded memory, four-file UI) and
  its real tooling (`make replay`/`sim`/`loadtest`, `tools/trap_sim.py`). `SECURITY.md` scopes
  the actual modules (`src/netcorenoc/receiver.py`, `auth.py`, `rbac.py`, …) and states the SNMP
  intake residual risk from the threat model. The disclosure policy makes **no unfounded
  promises**: good-faith response *targets* (not SLAs) and an explicit no-bounty statement.
- **`security.txt` validates.** `tests/test_security_txt.py` parses it per RFC 9116 (mandatory
  `Contact` + `Expires`, plus `Policy` and `Preferred-Languages`) and asserts `Expires`
  (2027-07-24) is in the future.
- **Its served route carries the existing CSP/security headers.** The route
  `GET /.well-known/security.txt` returns 200 **unauthenticated** with
  `Content-Type: text/plain; charset=utf-8` and the full `SECURITY_HEADERS` set (CSP identical to
  every route class, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`). It is
  additive to `STATIC_ASSETS` — a static file, not a new dynamic surface; the served bytes equal
  the shipped file. An `/api` route with no credential is still 401, proving the well-known file
  is deliberately public.
