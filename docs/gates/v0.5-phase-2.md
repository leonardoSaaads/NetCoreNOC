**Import-grouping normalization.** The `src/` move makes `netcorenoc` correctly first-party for
ruff's isort. To avoid churning files, the eval/tools/test helper modules are classified
`known-local-folder`; the only remaining change is a conventional blank line before the
`netcorenoc` import group in ~20 test files. The shipped `src/netcorenoc/*` files already
followed that convention and are **untouched**. Every changed test file's diff is import-grouping
only — no assertion touched (verified line-by-line). DECISIONS #40.

## New tests (the reorg didn't break anything)

`tests/test_structure.py` (24 tests, stdlib-only, no new dependency):

- **Structure guard:** the `src/` layout resolves (`netcorenoc.__file__` is under `src/`); the
  import path is unchanged; every runtime submodule imports; the expected top-level tree and docs
  taxonomy exist; the flat `netcorenoc/` and retired `opticorr/` do not reappear.

  cross-reference. Runs under `make test`/`make linkcheck`.

already ships the full UI + migrations under `src/`.
