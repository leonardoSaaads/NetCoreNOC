## Frozen: RBAC permission map

Capabilities are named as `<verb>` strings keyed to routes in `rbac.py`. `viewer ⊆
editor ⊆ admin` (each role inherits the ones to its left).

| Capability (permission id) | viewer | editor | admin |
|---|:--:|:--:|:--:|
| `situations.read`, `graph.read`, `timeline.read`, `stats.read`, `classes.read`, `events.stream` | ✔ | ✔ | ✔ |
| `feedback.write` (confirm/split) | — | ✔ | ✔ |
| `label.write` (rename devices/classes) | — | ✔ | ✔ |
| `situation.close` (close/ack) | — | ✔ | ✔ |
| `users.manage`, `tokens.manage` | — | — | ✔ |
| `config.write` (allowlist, retention) | — | — | ✔ |
| `quarantine.read` (audited read) | — | — | ✔ |
| `audit.read`, `audit.export`, `audit.prune` | — | — | ✔ |

HTTP semantics (frozen): `401` unauthenticated · `403` authenticated but insufficient ·
`404` only after authorization passes · deny-by-default (a route missing from the map
fails closed **and** fails CI).

## Frozen: audit event catalog

Every action below emits exactly one `audit_log` row; denied (403) attempts on sensitive
actions are audited too. Phase-4 asserts this catalog exhaustively.

- **auth**: `login.ok`, `login.fail`, `login.lockout`, `logout`, `password.change`
- **management**: `user.create`, `user.update`, `user.delete`, `role.change`,
  `token.create`, `token.revoke`, `config.change`
- **operation**: `feedback`, `label.set`, `situation.close`, `prune.manual`
- **sensitive reads**: `quarantine.read`, `audit.read`, `audit.export`,
  `legacy_token.used`

Row fields (frozen): `ts, actor, role, source_ip, action, object_type, object_id,
outcome ∈ {ok, denied, error}, details`. `details` is a JSON object redacted at the call
site — never a password, session id, token value, or community string.
`canonical = json.dumps({id,ts,actor,role,source_ip,action,object_type,object_id,outcome,
details}, sort_keys=True, separators=(",",":"))`;
`entry_hash = sha256(prev_hash + canonical).hexdigest()`; genesis `prev_hash` = 64 zeros.

## Frozen: password policy

- Algorithm `hashlib.scrypt`, parameters `n=2**17, r=8, p=1, dklen=32,
  maxmem=256*1024*1024`; 16-byte `os.urandom` salt per user.
- Stored form `scrypt$<n>$<r>$<p>$<salt_b64>$<hash_b64>` (parameters upgradeable later).
- Verification via `hmac.compare_digest`.
- NIST SP 800-63B: minimum 12 characters, maximum 128, no composition rules, no periodic
  expiry. (scrypt memory footprint 128·n·r = 128 MiB < 256 MiB maxmem — consistent.)

## Frozen: session policy

- Id `secrets.token_urlsafe(32)`; **stored as its SHA-256 hex**.
- Columns: `user_id, created_at, last_seen_at, idle/absolute expiry hints, source_ip`.
- Cookie `opticorr_session`, flags `HttpOnly; SameSite=Strict; Path=/`, `Secure`
  automatically when TLS is enabled.
- Idle timeout 30 min (sliding); absolute timeout 12 h.
- Logout deletes server-side; any password or role change revokes **all** of that user's
  sessions; expired sessions purged by the maintenance loop.
- A fresh id is issued at every login (fixation defence).

## Frozen: login-throttle policy

- After 5 consecutive failures per username **and** per source IP: exponential delay
  1 s → 2 s → 4 s → … capped at 15 min; counter resets on success.
- Identical error message and identical timing path for unknown-user and wrong-password
  (a dummy scrypt hash is computed when the user does not exist).
- In-memory, single process (DECISIONS entry in Phase 3). Failures and lockouts audited
  (`login.fail`, `login.lockout`).

## Frozen: CSRF policy

Applies to cookie-authenticated mutating requests only (bearer-token requests are exempt).
For every POST/PUT/PATCH/DELETE: (a) `Origin` (or `Referer`) host must equal `Host`, else
403; (b) header `X-OptiCorr-Client: ui` required. `SameSite=Strict` is the third layer.

## Findings F1–F6 in the threat model

Each finding appears in `docs/threat-model.md` with a planned control and a named Phase-4
test: F1 (UI stored XSS → `esc`/CSP/vendored d3, `test_f1_xss_*`), F2 (shared token →
sessions+service tokens, `test_f2_*`), F3 (secret in logs → redaction filter + scan,
`test_f3_secret_leak_scan`), F4 (community persisted → HMAC tag + quarantine sanitize,
`test_f4_*`), F5 (no TLS → optional TLS + `Secure`, `test_secure_flag_with_tls`), F6
(`0.0.0.0` default → warning banner, `test_f6_warning_banner`).
