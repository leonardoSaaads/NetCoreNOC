## Gate 1 checklist

1. **Harness is deterministic across two consecutive runs.** `test_harness_is_deterministic`
   runs `run_all()` twice and asserts byte-identical JSON; verified locally
   (`diff` of two `--json` runs is empty). Determinism rests on a fixed base clock, event
   ordering by `delay`, no `time.time()` in the scored path, a synthetic queueing model for
   latency (Decision 18), and `ORDER BY` on every read. **PASS.**
2. **Baseline committed.** `eval/baselines/v0.2.0.json` is frozen and never edited after this
   phase; `make eval` diffs against it and CI fails on a gated regression. **PASS.**
3. **Every §6 threat is in the threat model with a control and a planned Phase-4 test.**
   Entity-key XSS, entity-cardinality DoS, profiler memory DoS, learning poisoning, silent
   misattribution, the new RBAC capability, and the four new audit actions all appear in the
   v0.3.0 threat-model section with a named control and test. **PASS.**
4. **Corpus covers the targeted phenomena.** `test_corpus_covers_the_targeted_phenomena`
   asserts PON proxying (`pon_dying_gasp`), multi-level containment (`pon_pon_port_down`,
   `chassis_card_fail`), decoy varbinds (`decoy_varbinds`), dual incidents (`dual_incident`),
   and SNMPv1 traps (`camera_nvr`). **PASS.**

`make qa` gains the evaluation step; `make eval`, `make eval-baseline`, `make corpus`, and
`make burst` are wired; CI runs `make eval` and fails on regression in `pairwise_f1`, `ari`,
or `entity_accuracy` beyond a 0.01 tolerance.

## What the baseline proves about v0.2.0 (the gap v0.3.0 closes)

- **Proxied entity attribution is near zero.** olt_storm 0.002, pon_dying_gasp 0.003,
  chassis 0.020: every alarm is attributed to the reporting NE, so the true entity (ONU,
  port, card) is lost. Aggregate `entity_accuracy` 0.032 is the number v0.3.0 must lift.
- **The instance heuristic fails both ways.** decoy_varbinds `dedup_ratio` 1.000 (a serial
  varbind becomes the instance, so nothing deduplicates) and pon_pon_port_down `dedup_ratio`
  0.020 (a shared port varbind becomes the instance, so 300 ONUs collapse into 4 alarms) are
  the two silent-failure modes named in SCOPE-0.3 §Theme, captured as numbers.
- **SNMPv1 is invisible.** 400 camera traps quarantined; v0.2.0 sees no cameras at all.
- **Grouping is already good and must be preserved** (`pairwise_f1`/`ari` ≈ 1.0); the one
  weak spot, dual_incident (0.636), is v0.2.0's same-window co-occurrence over-merge, which
  v0.3.0 must not worsen.
