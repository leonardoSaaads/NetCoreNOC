# v0.15.3 — the console, designed

<!-- release-claim: v0.15.3 = console-design -->

**One paragraph, and it stays one paragraph until v0.15.2 exists.**

v0.15.3 is whatever v0.15.2 leaves undone, and that cannot be written now without inventing it. What
is knowable today is the shape of the boundary: v0.15.2 is a repair release with four measured
defects and a health screen ([`v0.15.2-console.md`](v0.15.2-console.md)), and a repair release that
also chooses a type scale, an icon system and a colour ramp is two releases wearing one version
number — neither of which a reviewer can read. So the question v0.15.3 exists to answer is *"what
does this product look like"*, and the reason it is a separate release is that the answer is a
judgement rather than a defect. Write it when v0.15.2 has shipped and its §7 has real answers, not
before: a design brief written against a console that is about to change in four places is a brief
about the wrong console.
